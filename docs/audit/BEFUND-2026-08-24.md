## Layer 3: Build ❌ BLOCKER

### Befund

- `NODE_OPTIONS=--max-old-space-size=8192 next build` → **OOM crash**
- Error: `FATAL ERROR: Reached heap limit Allocation failed - JavaScript heap out of memory`
- Build läuft ~18 Minuten, dann crash bei 8GB

### Severity: BLOCKER

Produktions-Deployment ist nicht möglich. `next build` muss erfolgreich durchlaufen.

### Root-Cause-Analyse

Mögliche Ursachen:

1. **Große Content-Dateien:** `dashboard.ts` (11.347 Zeilen), `corpus-meta.ts` (10.525 Zeilen) — werden komplett in den Build-Graph geladen
2. **Viele API-Routes:** 306+ Routes müssen einzeln compiliert werden
3. **React Compiler:** `reactCompiler` ist als Experiment aktiviert — kann memory-spike verursachen
4. **Bundle-Size:** 341K Zeilen Code, viele große Komponenten

### Fixes (BLOCKER)

1. **Sofort:** `reactCompiler` in `next.config.ts` deaktivieren (falls nicht critical)
2. **Heap auf 12-16GB erhöhen:** `NODE_OPTIONS=--max-old-space-size=16384`
3. **Content-Dateien splitten:** `dashboard.ts` (11K Zeilen) in Module aufteilen
4. **Bundle-Analyzer laufen lassen:** `ANALYZE=true next build` um große Chunks zu identifizieren

3. **`dompurify` update:** Auf ≥3.4.13 (fixt XSS bypass)
