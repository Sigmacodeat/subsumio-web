## 10. Risiken & Handlungsempfehlungen

1. **HNSW-Index-Parameter:** Derzeit `m=8, ef_construction=32`. Für Produktionsrecall besser `m=16-32, ef_construction=128-200` nach Abschluss des laufenden Rebuilds.

2. **halfvec-Migration:** `embedding_half` existiert nicht — Speicheroptimierung von 50 GB Chunks ausstehend.

3. **AT VwGH:** Von 104.542 lokalen Files sind 103.644 Platzhalter (`Volltext nicht abrufbar`); nur 898 haben echten Volltext. Die DB hat 22.523 Pages aus einem älteren Import (wahrscheinlich mit damals noch anders strukturiertem RIS-Inhalt). RIS-OGD known total VwGH beträgt 356.331 → DB-Deckung nur ~6 %. Bei Re-Sync droht Überschreibung/Stale-Content.

4. **EU-Verordnungen:** 40.715 Pages aus federated Source (`law-eu-regulations`, `federated: true`). Keine lokalen `.md`-Dateien; Inhalt wird direkt von EUR-Lex/eu-lex API synchronisiert. Keine klassische Ingest-Lücke, aber **Backup-/Audit-Trail-Lücke**: falls externe API wegfällt oder Case-Nr. sich ändert, gibt es kein lokales Original.

5. **Link-Extraktion:** `links_extracted_at` ist für alle 385.794 Pages NULL — Graph-Links können nicht aktualisiert werden.

6. **Contextual Retrieval:** 98% `title`, nicht `parent`/`sibling` — ggf. Re-Chunking für besseren Kontext erwägen.

7. **HNSW-Rebuild im Gange:** Vector-Search läuft derzeit auf altem/sekundärem Index; keine Optimierung, bis Rebuild finalisiert.
