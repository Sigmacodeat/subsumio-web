# Keyword-Research: 23 Nischen-Landingpages

> Stand: Juli 2026 · Basis: Google Keyword Planner Schätzungen (DE/AT), SERP-Analyse, Wettbewerbs-Recherche
> Status: Living Document — wird mit neuen Suchvolumen-Daten aktualisiert

## Methodik

- **Primärkeywords**: Haupt-Suchbegriff pro Nische (im Meta-Title, H1, Intro)
- **Sekundärkeywords**: Unterstützende Keywords (in H2, FAQ, Content)
- **Long-Tail**: Spezifische Suchanfragen mit geringerem Volumen aber hoher Conversion-Intention
- **Suchvolumen**: Monatliches Suchvolumen DE/AT (gerundet, Google Keyword Planner)
- **Konkurrenz**: Niedrig = <10 starke SERP-Results, Mittel = 10-50, Hoch = >50
- **CPC**: Cost-per-Click Schätzung (Google Ads) als Indikator für kommerziellen Wert
